# ex-1-et-2-tp2
TP HTML & CSS — Reproduction d’interfaces
📌 Description

Ce projet contient la réalisation de plusieurs interfaces graphiques en utilisant HTML et CSS pur, basée sur des figures données (Figure 1 à Figure 5).

L’objectif principal est de maîtriser différentes techniques de positionnement en CSS ainsi que la structuration d’une interface responsive.

🎯 Objectifs pédagogiques

✔ Comprendre et appliquer :

Le positionnement absolu (position: absolute)
Le positionnement relatif (position: relative)
L’organisation des blocs en CSS
La structuration d’une page HTML propre

✔ Reproduire fidèlement des maquettes (figures)

✔ Introduire les bases du responsive design

✔ Refaire les interfaces avec Bootstrap

🧩 Contenu des exercices
🔹 Exercice 1

Reproduction des Figures 1 à 4 avec deux méthodes différentes :

✅ Méthode 1 : Positionnement absolu
Utilisation de position: absolute
Placement précis des blocs
Indépendance totale des éléments
✅ Méthode 2 : Positionnement relatif
Utilisation de position: relative
Déplacement par rapport à la position initiale
Approche plus fluide

Figure 1 : Alignement vertical
Figure 2 : Disposition en escalier
Figure 3 : Bloc principal + blocs secondaires
Figure 4 : Alignement mixte
